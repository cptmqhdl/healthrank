## 수집된 데이터 (2026-08-12 기준, 매일 실행하면 그날 날짜로 새로 쌓임)

- `data/raw/카카오선물하기_YYYY-MM-DD.csv` — 20개 (건강식품·영양제) → 화면엔 1~10위만
- `data/raw/다이소몰_YYYY-MM-DD.csv` — 27개 (식품 랭킹) → 화면엔 1~10위만
- `data/raw/올리브영_YYYY-MM-DD.csv` — 5개 (건강식품 BEST) → 5개 전부 화면에 표시
- `data/latest.json` — 위 CSV들을 화면 표시용으로 가공한 파일 (사이트별 1~10위 + 전날
  대비 순위 변동). `report.html`이 직접 읽는 파일이며, 매일 자동으로 다시 만들어짐

## 크롤러 직접 실행하는 법

각 스크립트를 더블클릭은 안 되고, 아래처럼 실행합니다 (다음 단계에서 자동화 예정):

```
python scripts\crawl_kakao_gift.py
python scripts\crawl_daiso.py
python scripts\crawl_oliveyoung.py
```

## 파일 구성

- `report.html` — **판매순위 대시보드**(사이트별 1~10위, 썸네일·클릭 링크 포함).
  `data/latest.json`을 불러와 화면을 그리므로, 웹 서버 없이 파일을 그냥 더블클릭하면
  브라우저 보안 정책 때문에 데이터가 안 보일 수 있습니다 — 위 깃허브 페이지 주소로
  보는 걸 권장합니다.
- `설계서.md` — 기술적인 설계 내용(데이터 구조, 크롤링 방식, 아키텍처, 로드맵). 개발이 진행될
  때마다 이 파일을 계속 업데이트합니다.
