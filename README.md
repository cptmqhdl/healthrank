## 수집된 데이터 (2026-08-12 기준, 매일 실행하면 그날 날짜로 새로 쌓임)

- `data/raw/카카오선물하기_YYYY-MM-DD.csv` — 건강식품·영양제 랭킹 1~10위 (광고 상품 제외)
- `data/raw/다이소몰_YYYY-MM-DD.csv` — 건강식품 카테고리별 랭킹 1~10위
- `data/raw/올리브영_YYYY-MM-DD.csv` — 판매랭킹 · 건강식품 1~10위
- `data/latest.json` — 위 CSV들을 화면 표시용으로 가공한 파일 (사이트별 1~10위 + 전날
  대비 순위 변동). `report.html`이 직접 읽는 파일이며, 매일 자동으로 다시 만들어짐
- `data/monthly/{YYYY-MM}.json` — 그 달 CSV들을 모아 계산한 월간 집계(평균 순위·1위
  횟수·노출일수 등). `data/monthly/index.json`에 집계된 달 목록이 있고, 대시보드의
  "월간 리포트 보기" 버튼이 이 파일들을 불러와 보여줌. 매일 자동으로 이번 달 파일만
  다시 계산되고, 지난 달 파일은 그대로 보관됨

## 크롤러 직접 실행하는 법

각 스크립트를 더블클릭은 안 되고, 아래처럼 실행합니다 (다음 단계에서 자동화 예정):

```
python scripts\crawl_kakao_gift.py
python scripts\crawl_daiso.py
python scripts\crawl_oliveyoung.py
```

## 파일 구성

- `report.html` — **판매순위 대시보드**(사이트별 1~10위, 썸네일·클릭 링크 포함).
  `data/latest.json`을 불러와 화면을 그리므로, 웹 서버 없이 파일을 그냥 더블클릭하면
  브라우저 보안 정책 때문에 데이터가 안 보일 수 있습니다 — 위 깃허브 페이지 주소로
  보는 걸 권장합니다.
- `설계서.md` — 기술적인 설계 내용(데이터 구조, 크롤링 방식, 아키텍처, 로드맵). 개발이 진행될
  때마다 이 파일을 계속 업데이트합니다.

## 사용법

1. https://cptmqhdl.github.io/healthrank/ 로 접속해 오늘의 판매순위를 확인합니다.
2. 이번 달(또는 지난 달) 순위 흐름이 궁금하면 "월간 판매랭킹 리포트" 섹션에서 달을
   고르고 "월간 리포트 보기" 버튼을 누릅니다.
3. 화면 구성이나 표시 방식에서 고치고 싶은 부분이 있으면 편하게 말씀해주세요.
