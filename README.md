# 건강기능식품 데일리 판매순위 대시보드

카카오톡 선물하기, 다이소몰, 올리브영 세 곳의 건강기능식품 판매순위를 매일 자동으로 모아서
한 페이지에서 보고, 월말에는 월간 리포트까지 자동으로 만들어주는 개인용 도구입니다.

## 깃허브 저장소

- https://github.com/cptmqhdl/healthrank (비공개 저장소)
- 매일 09:30(한국시간)에 자동으로 세 사이트를 수집해서 `data/raw/`에 새 CSV를 커밋합니다.
- 수동으로 지금 바로 실행해보고 싶으면: 저장소 페이지 → Actions 탭 → "데일리 건강기능식품
  판매순위 수집" → Run workflow 버튼
- 2026-08-12 실제 테스트 실행 성공 확인: 카카오(20개) · 다이소몰(28개) · 올리브영(5개)
  모두 수집 → 자동 커밋까지 정상 작동

## 수집된 데이터 (2026-08-12 기준, 매일 실행하면 그날 날짜로 새로 쌓임)

- `data/raw/카카오선물하기_YYYY-MM-DD.csv` — 20개 (건강식품·영양제)
- `data/raw/다이소몰_YYYY-MM-DD.csv` — 27개 (식품 랭킹)
- `data/raw/올리브영_YYYY-MM-DD.csv` — 5개 (건강식품 BEST)

## 크롤러 직접 실행하는 법

각 스크립트를 더블클릭은 안 되고, 아래처럼 실행합니다 (다음 단계에서 자동화 예정):

```
python scripts\crawl_kakao_gift.py
python scripts\crawl_daiso.py
python scripts\crawl_oliveyoung.py
```

## 파일 구성

- `report.html` — 지금까지 인터뷰한 내용 요약, 추천 방향, 대시보드 화면 미리보기(샘플 데이터).
  더블클릭해서 브라우저로 열어보세요.
- `설계서.md` — 기술적인 설계 내용(데이터 구조, 크롤링 방식, 아키텍처, 로드맵). 개발이 진행될
  때마다 이 파일을 계속 업데이트합니다.

## 사용법

1. `report.html`을 더블클릭해서 웹브라우저로 엽니다.
2. 방향이 마음에 들면 다음 단계(실제 크롤러 제작)로 넘어갑니다.
3. 고치고 싶은 부분이 있으면 편하게 말씀해주세요.
