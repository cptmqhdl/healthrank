기술 스택

Python 크롤러 + 정적 대시보드

  • 수집: Python (requests/BeautifulSoup, 필요 시 Playwright)
  • 저장: CSV → 필요해지면 SQLite
  • 화면: HTML + JS (Chart.js), 이후 서버 연동
천천히 키워도 되는 프로젝트라, 처음부터 크게 짓지 않고 파일 기반으로 시작해 필요할 때만 넓히는 구조가 유지보수에 유리해요.
추천 툴

Claude Code + 작업 스케줄러

  • 크롤러 개발/유지보수: Claude Code
  • 매일 자동 실행: Windows 작업 스케줄러
  • 백업·수동 확인: 엑셀 (이미 다룰 줄 아시는 도구)
이미 엑셀에 익숙하시니, 원본 데이터는 항상 엑셀로도 열어볼 수 있게 CSV로 남겨두면 안심하고 검증할 수 있어요.
UI / UX

탭 전환 + 카드 그리드

  • 사이트별 탭으로 전환 (카카오/다이소/올리브영)
  • 순위는 카드 그리드로 한눈에 비교
  • 월간 리포트는 스크롤형 요약 문서
사이트마다 성격이 달라서 탭으로 나누는 게 자연스럽고, 핵심 지표(순위·가격)는 카드로 볼 때 가장 빨리 비교돼요.
